# Учебный проект по ТРПО

Шахматный визуализатор на C — учебная лабораторная работа по дисциплине «Технология разработки программного обеспечения» (СибГУТИ).

## О проекте

Цель работы — научиться пользоваться Git и попробовать написать тесты.

В проекте реализованы:

- библиотека `libchessviz` для работы с шахматной доской и разбора ходов;
- консольное приложение `chessviz`, которое печатает доску;
- модульные тесты на `ctest` для проверки логики.

## Структура

- `src/libchessviz/` — библиотека: `board` (доска) и `board_move` (ходы)
- `src/chessviz/main.c` — консольное приложение
- `test/` — модульные тесты
- `makefile` — сборка проекта
- `thirdparty/ctest.h` — тестовый фреймворк
- `.clang-format` — стиль кода

## Сборка

```
make
```

## Тесты

```
make test
```
